# Bundled fonts (added 2026-11-08, approved by Petey K)
Both are SIL Open Font License 1.1 (license texts are alongside). Each file is converted from TTF to WOFF2 with the same glyphs and metrics and no subsetting.
- Inter-Variable.woff2: Inter Version 4.001;git-66647c0bb, pinned at opsz 14 (the size the installed system font rendered the approved mockup at, so its proportions match exactly); wght axis 100–900 kept. Source: Google Fonts Inter-VariableFont_opsz,wght.ttf (sha256 0be2399e…ac3a8), the same file used to render the approved mockup. Upstream https://github.com/rsms/inter
- SpaceGrotesk-Variable.woff2: Space Grotesk Version 2.000, axis wght 300–700. Source: Google Fonts SpaceGrotesk-VariableFont_wght.ttf (sha256 697a7905…2b142). Upstream https://github.com/floriankarsten/space-grotesk
Italic styles are not used on the site, so they are not bundled.
